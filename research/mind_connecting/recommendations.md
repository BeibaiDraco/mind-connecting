# Which question should the next paper pursue?

2026-10-20. This is research discovery and a pilot proposal, not a new formal protocol or authority to start a model run. The PI does not require the old paper to remain the center. **Prioritize selective information use versus decision control (A); develop connection-dependent self-capacity prediction (B) as a genuinely different potential main story.** Use reciprocal adaptation (C) only when the relevant claim needs it and the information path works. Publication prospects depend on new evidence; none of these is an already-validated final experiment.

The broad question is how the boundary of a computational agent is functionally organized when another active agent's internal states become available. Three observations should stay separate: what it can use, what controls its action, and what it thinks it can do without the partner. A single vivid misattribution or cooperation score cannot substitute for all three.

## A. Borrow evidence while retaining local decision control

The motivating observation is not just old memory claiming. Recent development cases preserve own-goal labels while rule answers change, with poor partner-fact access. This suggests a possible separation between maintained goal labels and their use, but the fixed-scene study committed no actions. [Coverage checks](card_checks/discovery_checks_20261020.json) confirm that distinction. A study of actual selective control can therefore be new relative to our previous work, without assuming a changed internal goal.

### A minimal diagnostic world

Two agents have private observations `xA,xB` and private assigned goals `gA,gB`, each binary. The focal A has two buttons. Under goal 0 it must match B's observation; under goal 1 it must choose the opposite. Thus `aA*=xB XOR gA`; symmetrically `aB*=xA XOR gB`. Render the rule in ordinary language, not as a required XOR calculation. Vary surface labels/button order independently. Assigned goals are experimental task commitments, not evidence of intrinsic desires.

Use all sixteen combinations of `xA,xB,gA,gB` for a complete local response map. A change in `xB` should reverse A's appropriate action; a change in `gA` should also reverse it; changing only `gB` should not. Varying `xA` distinguishes copying the partner's ideal action from applying the partner's goal to B's observation. These are interventions within a layout family, not sixteen independent samples. Actual copying must also be checked against the partner's observed action, not just its ideal action.

The existing [symbolic check](card_checks/discovery_checks_20261020.py) shows why aggregate accuracy is inadequate: five different wrong strategies each score 50%. It also shows an important non-identifiability: using a distorted fact `xB XOR gA XOR gB` with the correct own goal produces the same actions as using `gB`. A crossed response map identifies functional selectivity, not which hidden representation was overwritten. A later mechanism claim would require an additional mediator intervention, and may warrant a richer action alphabet.

### Small comparisons worth implementing next

First verify the disconnected private task with both required facts explicitly provided. This is an oracle capability control, not the bridge. Then compare OFF, actual donor-generated text, and a bounded set of internal interfaces. Actual generated text must retain donor errors; it cannot be replaced with the ground truth. Keep the previous free-planning all-layer interface as a reference. First vary only exported segment (unrestricted planning versus designated observation generation); separately vary receipt/private-action timing. Neither manipulation claims to purify contextual K/V into a fact-only representation. Recipient layer selection is a later, independently characterized factor if these comparisons expose an unresolved problem, not a blind sweep for the largest self effect.

From one post-exposure state, obtain separate restored branches for (i) native actual action, (ii) partner-fact report, (iii) originally assigned own-goal report, and (iv) historical source of the partner observation. Define the known truth for the last two separately; remembering an assigned goal cannot substitute for identifying an observation's origin. Incoming connection is off during these diagnostic branches so direct answer-time steering does not masquerade as a retained effect. Keep a separately labeled linked-answer comparison if needed. These single-step action branches do not yet establish a persistent interactive history. A later live test must commit the actual native choices and update the world accordingly.

Proposed quantities per independently generated layout family: action correctness; joint correctness of both paired actions under a partner-fact flip; sensitivity to a task-irrelevant donor-goal flip at fixed own inputs; action agreement with prespecified candidate policies; original-source errors; and invalid-output counts. Report the full response pattern. Task correctness, fact report and source report are not interchangeable. Attribute effects initially to the donor-assignment intervention, which changes the full donor computation, not to a uniquely isolated semantic goal vector.

**Promising results:** effective partner-fact use with preserved local-goal behavior but impaired source attribution; or reproducible donor-assignment sensitivity despite demonstrably usable facts, localized to an interface/timing manipulation. Preserved selectivity with accurate attribution is also meaningful evidence, especially if contrasted with a harmful interface. **Weak result:** all connected arms simply impair everything. That would guide engineering or a bounded limitation report, not establish a distinctive self phenomenon.

## B. Does the model understand its connection-dependent abilities?

This candidate can become the main paper independently of old ownership errors. One agent has context that enables a class of tasks unavailable to the other alone. The question is whether the recipient distinguishes “I can do this with current access,” “I can now do it without further access,” and “I still need the partner.” No model weights or interface are trained; this is context-enabled competence, not transferring a learned weight-level skill.

A minimal task can use a changing private lookup/rule held by B and a fresh challenge for A. A must use the received information for an actual decision. Both sides can later have complementary private information. Crucially, verify connected/cut performance on paired challenges: receiving a complete lookup may let A continue correctly after cutting the channel. Such retention is a real result, not a failed manipulation to conceal. Retain a pre-exposure/no-access competence comparison; post-cut success alone does not establish acquisition. New partner-private updates can establish ongoing dependence only if the measured performance confirms it.

### Proposed forecast/action computation

After a bounded history in a specified regime, save state. In restored forecast branches ask for explicit 0–100 probabilities of correct performance on the displayed upcoming challenge under (a) continued designated access and (b) no further access after this state. For each valid parsed percentage `p`, define `q=p/100`, giving `q_on,q_off` in [0,1]; retain invalid responses as invalid, never zero. Wording and probability-format comprehension need a pilot; candidate-token log probabilities are not automatically semantic confidence. Separate restored action branches obtain actual native choices and correctness outcomes `y_on,y_off` in {0,1} under those exact conditions. Missing/invalid action observations are recorded separately rather than imputed; report their rates and the scope of each valid-pair estimate. Forecast branches never enter the action history.

Across independently generated episodes, compare predicted dependency `q_on-q_off` with empirical paired dependency `y_on-y_off` and calibration of each forecast. Compute Brier loss `(q-y)^2` for each valid challenge and branch first, then average these losses within each episode, then average the episode means with equal episode weight. Never square the difference between episode-averaged forecasts and outcomes. Average paired dependency contrasts within episode before combining episodes; report valid denominators separately for each quantity. For a later confirmatory study, bootstrap at episode level and preregister the primary comparison; no inferential result is calculated here. Do not select cases because a favorable calibration contrast appears.

Also test choice to request help versus act alone in a separate actual-policy experiment, with a declared cost/reward structure; that structure is not yet selected. Separate prediction from decision: a forecast can itself affect subsequent behavior, while a real help decision necessarily enters the trajectory.

Availability/history must be accessible **before** forecasting. Conditional hypothetical forecasts are distinct from guessing the current undisclosed regime. If regime changes are undisclosed, give a bounded exposure/feedback period before prediction and keep that regime stable through the challenge. Do not randomize a hidden future condition after prediction and call failure poor self-knowledge. Compare disclosed and undisclosed conditions, actual donor-generated text, a transcript-matched same-model observer, and a feedback-history predictor. Accurate forecasting can reflect ordinary inference; it is not automatically privileged introspection.

Before implementation, the PI must adopt the exact forecast-time connection schedule and the observer's information/computation access. These are unresolved scientific choices: extra incoming states while forecasting or a poorer observer transcript can manufacture an apparent self-prediction advantage. Freeze these choices before any B collection rather than leaving them to an implementer's default.

**Promising results:** forecasts accurately track acquisition versus dependence; or measured new ability changes while forecasts systematically overstate autonomous ability, beyond relevant matched controls. **Weak result:** confidence rises whenever the prompt says help is available; or forecasts are meaningless even in explicit-text conditions. The latter blocks this endpoint without invalidating A. Generic confidence and delegation already have close precedents in [field.md](field.md).

## C. Add responsiveness when it answers a remaining question

Once information use is interpretable, retain two persistent histories and actual world updates. Branch from the same pair state, change one private input, and trace an appropriate A-to-B-to-A response. Compare the same recipient operator with directional cuts, counterfactual replay and fresh open-loop signals. Record available information, timing and computation. Counterfactual live signals will differ from replay; those differences carry the causal response rather than being removable nuisance. A fresh donor inheriting actual past histories is not independent of all prior interaction.

Partner-specific adaptation additionally requires matched partner swaps/cross-play and controls for different private knowledge and exposure. More rounds alone do not identify it. This is a later opportunity, not a prerequisite for every publishable one-way control or self-capacity finding.

## Research sequence and decisions

1. Implement and validate the small balanced world and separate measurements locally; confirm branch semantics, role permutations and invalid-output handling. No new model execution is implied.
2. Propose one finite exploratory batch for A. Use few new layout families covering the meaningful interventions; number, interface list, limits and costs remain to be set. Keep failures. Select interfaces using separately measured transfer/ordinary task competence, not the biggest source/control effect.
3. If a usable information-access effect is empirically characterized, including retained acquisition or ongoing dependence, add the short B forecast/action pilot. If the probability task fails, do not launch a confidence battery. If A only reveals structured interference, test specificity rather than pretending cooperation has been achieved.
4. Choose the paper's core from the informative result and its closest-precedent comparison. New independent confirmation follows that choice. Preserve all developmental exposure and frozen historical failures; don't relabel exploration as confirmation or alter old N/gates.

All candidates are pilot-worthy or conditional; none is certified as a finished, novel, fully powered protocol. The recommendation is to spend the next experiment on a discriminating question, not to collect every proposed branch at once.
