# Recommended next investment: how shared commitments change complementary inquiry

October 26, 2026. **Conditional research plan; final substantive refinement (repair 2 of 2).** Recommend one finite task-and-channel feasibility study followed, only if its prerequisites hold, by a causal diagnostic. This is not an adopted protocol or an authorization to run models. The [development decision](development.md) records the first identifiability check; the [renewed source/runtime audit](source-and-runtime-check.md) supplies the strongest current comparisons. Retain the [previous source audit](../flagship_20261026/questions/responsiveness/source-evidence.md) and [independent repair-1 review](../flagship_20261026/questions/responsiveness/review.md).

## The question and its possible value

**When internal sharing conveys a partner's committed investigation, does the recipient use it to investigate the missing part of the world, or does that signal change its choice in a way that duplicates evidence—and which incoming state and processing stage cause that change?** Both instances have one shared objective. There is no conflicting goal, ownership report or personal-identity claim.

The proposed result is a causal explanation of how communication changes a team's production of information. **Useful internal communication between two LLM instances is mandatory for this direction.** Text is a competence/comparison condition, not a text-first substitute or fallback project if the native route fails. It is not the generic discovery that isolation can improve exploration: ArcticSwarm, Bernstein and other predecessors already establish close versions. The potential added value is a response rule that predicts actual measurement choices under interventions on the partner's commitment and instrument calibration, then survives fresh materials and a second acquisition family. A finding confined to a two-button toy remains a useful diagnostic. Neither generic search diversity nor use of a native carrier establishes a native-specific phenomenon. A claim that knowledge is preserved while a pure action representation is imported requires evidence this plan does not promise.

## Exact minimal task and timing

The environment holds independent balanced bits `x,y`; both are unknown to both models. A's buttons L/R measure x/y. B's public calibration is independently randomized: aligned L/R→x/y or reversed L/R→y/x. Each has one measurement opportunity and the common objective is to identify the complete code. Randomize button names, component names, answer codebooks and physical leader side prospectively within episode families.

1. Save the pair before A's cue. Privately give A a fresh random availability cue permitting exactly one button. A issues an actual commitment; the environment validates and freezes it. A cannot revise it. Invalid commitments remain failures, not silently corrected probes.
2. A performs the fixed communication work interval after commitment. Export its last 16 eligible ordinary generated positions, all before any outcome exists in either model's input or state. An opposite-cue donor is generated from the pre-cue checkpoint with the other availability cue, also before observations. No branch receives x or y yet. Use equal-length cue templates and equal work counts so aligned export positions can be audited.
3. B receives the assigned early route and chooses one actual button. Only that committed action enters continuing history. Sibling diagnostic questions use discarded clones. After both commitments, the environment executes the measurements and privately reveals each value only to its measuring agent.
4. Apply the independently assigned late B→A gate. Its assignment is concealed throughout acquisition, including prompts, file-derived fields, clocks, receipts and available windows. A then submits the complete code. No further measurements are permitted. Exact post-observation forks can compare late ON/OFF from the same evidence state; these forks do not count as independent episodes.

The main early routes are native A→B, its opposite-cue native yoke, explicit source-tagged text of A's actual commitment, and no informative source. An exact same-payload replay is a technical integrity check. Neither yokes nor replay are selected from successful downstream trajectories. Record every actual measured or imported value; an information bound based only on physical probes is invalid if another channel leaked a bit.

An independently assigned **forced-complementary acquisition control** makes the environment deliver one actually measured component privately to A and the other privately to B, bypassing the acquisition policy. Late native ON/OFF then tests whether A can use useful partner evidence. This is a controlled intervention, not conditioning on naturally successful acquisition, and not a natural mediation decomposition.

## First stage: prerequisites, before acquisition effects are inspected

Implement the instrument world, complete information ledger, counterfactual lineage and rendered-input audit without model execution. Exhaustively check all four codes, both cues, both calibrations and late assignments. Confirm that pre-observation payload construction is invariant to hidden values and concealed late gates; native cache validity still requires later hardware checks. Confirm single-token action labels and preserve all invalid outputs.

Use one fixed native bridge configuration: the pinned frozen Qwen checkpoint, existing original native backend, gain 1.0, at most 16 exported positions, and a fixed work allowance proposed as 64 generated tokens per communication stage. These are inherited engineering starting points, not demonstrated task competence. Do not change gain, window length, prompt or work time after inspecting target acquisition effects.

Propose a **single development batch of 16 fresh layout families**, balanced over hidden codes and including both cues and calibrations. Admit on transparent full-information mapping/complement competence, valid actual commitments, donor-content access, general capability and useful forced-complementary late transfer. Suggested criteria for PI adoption are ≥90% transparent action accuracy, ≥95% valid commitments, native final-code accuracy ≥75% with at least a 20 percentage-point paired improvement over late-OFF, and no more than a 5-point drop on the fixed capability control. These are proposed task/ACC/CAP/format criteria, not frozen research thresholds or confidence guarantees from a small batch. Publish the complete counts and uncertainty; no acquisition-duplication effect enters admission.

The batch also tests native receipt of A's commitment with a neutral factual question, without using that sibling answer as proof of an action mechanism. Failure of the declared prerequisite ends this finite candidate test. Any interface development becomes a separate PI decision with new material; no automatic prompt/gain grid or larger model follows. Existing V6 does not establish these capabilities.

## Second stage: the finite causal diagnostic

After admission, use **24 new layout families**, all balanced cue/calibration variants within each family, and the four early routes above. Fork late ON/OFF only after measurement outcomes are fixed. With one hidden-code draw per family, this is 384 B action endpoints and 768 paired final-code endpoints, plus A commitments, capability checks and separately logged generation. This is an explicit development cap, not a formal sample size or GPU-cost estimate. Compute cost needs actual prospective timing and PI authorization.

Primary records are B's complete action response table under cue and calibration interventions, whether both components were acquired, final-code correctness, and the late-use effect in the forced-complementary control. Report invalid actions, missing trials and source disagreements separately. Acquisition loss means lower objectively measured coverage relative to a declared comparison, not merely more matching button names. Across balanced calibrations, a pure button-following policy can average the same coverage as uninformed behavior; it does not automatically establish harmful early sharing. Semantic duplication would instead lose coverage in both maps. Helpful complementary coordination is an equally admissible result.

Separate early sharing during B's fixed work interval from sharing during processing of its final action query in a prespecified 2×2 work/query gate diagnostic. Cap this diagnostic at the **prospectively fixed first eight of the 24 families**, selected by generated family ID before observing outcomes: eight families × two cues × two calibrations × four gate cells gives at most **128 supplemental B action endpoints**. Do not select the most affected families. Query-only comparisons restore the same B state and use byte-identical action question/prefix and work history; only the held foreign exports differ. This can establish whether incoming state at decision processing suffices to change actual actions. Work-only changes that persist with query sharing OFF implicate the changed continuing state/history as a bundle. Different generated work means they do not isolate cache from text. The existing probe adds and processes the full action query; call this a query-processing intervention, not an intervention exclusively on the last output neuron or token.

## Rival explanations and discriminating observations

| Candidate account | Required prediction or intervention | What remains unproved |
|---|---|---|
| Useful complementary coordination | B counterfactually changes with A's cue and remaps across calibration to measure the missing component; opposite-cue input predictably misdirects it | This does not require spontaneous reciprocal negotiation or a special self mechanism |
| Nominal action influence | B's response follows A's button despite calibration reversal, including at a fixed recipient action prefix when donor states are swapped | The same response can arise from calibration-dependent fact errors; the behavioral rule is not literal copying |
| Semantic-target following | B follows A's measured component across both calibrations | Wrong A-component belief, reversed calibration, or failure to complement can produce exactly this table |
| Incoming-query influence | Same-prefix query-only native swaps change actual B actions; effect disappears with the foreign window removed | This identifies a causal input/stage, not the semantic content represented inside B |
| Continuing-state influence | Work ON affects later committed actions with the query gate OFF | Persists in text/cache/work-history bundle; not necessarily durable memory or a distinct policy module |
| Generic disruption or formatting failure | Effects follow irrelevant donor changes, capability loss or invalid actions without the cue/map-predicted direction | Such outcomes cannot support a commitment-specific explanation |

Use action-task intervention controls, not only questions about facts: (i) supply an authoritative A-commitment record; (ii) supply an explicit B mapping table; (iii) supply the desired complementary component while requiring B to implement its own mapping. Keep common objective and values unchanged. Cap these controls at the **same prospectively fixed first eight families**, with two cue variants, two calibrations, the three scaffolds and native/OFF sharing: at most **192 supplemental B action endpoints**. These are separately labeled scaffolding interventions. Their effects can show that a bottleneck is bypassable and test an account's predictions, but they change the computation and can override several mechanisms. A correction rescuing performance does not uniquely locate the original failure. Correct sibling reports likewise do not rule out wrong action-branch beliefs. The exact aliases are derived in [development](development.md). The 384/768 primary-grid counts therefore exclude these 320 supplemental action endpoints, A commitments, prerequisite and forced-complementary controls, integrity checks and the optional state test. The complete workload has not yet been timed, costed or authorized; no total-run or dollar estimate is implied.

## Optional finite native-state test, with a deliberately limited claim

If the diagnostic contains a reproducible cue-dependent native effect, reserve **at most eight new layout families** for a prespecified follow-up. From the exact same B state before its action query, compare the complete factual-cue donor window with: the complete opposite-cue window; replacement of positions 1–8 only; replacement of positions 9–16 only; and exact original restoration. Each substituted export must be an actual generated native K/V state from the paired pre-observation counterfactual donor with identical absolute positions, shape and checkpoint. No synthetic zero vector, invented knowledge vector or covert layer/head sweep is used. Equal-length templates and exact export-position compatibility are admission requirements for this follow-up; if they fail, retain the whole-window comparison only and defer partial replacement.

This is a small causal localization of **transmitted state bundles**. Hybrid windows may be outside natural trajectories; opposite-cue whole-window controls, matched irrelevant-cue changes, preserved capability/format and restoration delimit that concern but cannot remove it completely. No late bit values enter these early windows. Reinstating the original bytes must reproduce the original distribution within the backend's prespecified numerical tolerance before interpreting any change. Restoration establishes reversibility and technical integrity; alone it does not identify the original cognitive operation.

The causal test runs on the actual action branch at an identical input prefix, rather than using a factual report from a sibling branch. It can establish that a specified bundle is necessary in this comparison or sufficient under the tested replacement, while neither proving semantic purity nor establishing a unique knowledge-versus-action mediator. Decoder probes, attention plots and textual interpretations may describe hypotheses but cannot carry those causal claims. Recipient-cache/head/layer surgery would require a separately reviewed implementation and independent functional characterization; it is excluded from the present finite plan.

## Confirmation, scope and stop rules

All development-localized effects remain exploratory. Freeze tasks, prompts, bridge, gates, state substitutions, primary contrasts and failure handling before fresh confirmation. Use the episode/layout family as the statistical unit; average its balanced cue/calibration variants before paired intervals. A/B sides, four hidden worlds, replay, final forks and diagnostic questions are not additional independent samples. The PI must choose a practically relevant effect/precision target; set formal N from independent pilot variance after parameters are frozen, never from the desired sign.

Before a flagship claim, test the frozen causal prediction in **one second family**, chosen before confirmation: two agents each choose one inspection of a device's wiring table, with instrument labels remapped across devices and a common final connectivity decision requiring both entries. A's new private access restriction again fixes its first inspection. Keep the same two-stage information structure while changing the representation and final composition. This is a closely related complementary-evidence family, not independent validation across substantially different kinds of inquiry; success alone cannot establish broad generalization or flagship importance. Competence on this family must be admitted independently. No automatic expansion follows if it fails.

Stop this native direction if controlled late information is unusable, transparent mapping competence fails, or native interventions violate the information ledger. Stop the commitment-specific explanation if only invalidity/global impairment appears or response changes do not track cue/map interventions. If stage effects alone survive, report a bounded behavioral causal result. If a reliable response rule survives state interventions and new families, it becomes a credible explanatory paper candidate, still constrained by direct precedents. If ordinary facts, calibration or complement scaffolding explain the results, report that ordinary account and do not rename it self-boundary transfer. Successful complementary sampling rejects the predicted duplication failure in the tested range and is valuable as a working channel demonstration; by itself it is not a flagship.

The repository already supports native state cloning, export serialization, discarded probes, sealed real action commitment and replay primitives. It does **not** yet implement this world, timing audit, hidden gates, second family, position-replacement validation or a reviewed runner/admission contract. The immediate concrete next investment is that bounded implementation-and-feasibility proposal for PI approval, not a paid run or a promise of a top-tier paper.
