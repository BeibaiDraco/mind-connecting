# Native access to alternatives after a shared leading answer

October 26, 2026. Proposed study; not a frozen protocol or authorized GPU run. Primary planner's completed draft, with bounded substantive repair 1 responding to independent findings R1/R2; repaired text awaits independent recheck. The experiment uses two separately initialized instances of pinned frozen Qwen3-4B-Instruct-2507. One-way transfer is enough for the decisive comparison; swap sender/recipient roles across episodes. This is direct internal communication between two models, without assuming a working reciprocal chain.

## Question and claim ladder

**Can a partner use the alternatives that your answer discarded?** This is the motivating question, not an established description of every episode. The experiment records the actual donor choice and distinguishes it from the constructed task-optimal leader. Specifically, can an imported native state enable the recipient to choose appropriately among donor-supported alternatives after a private late observation, when the donor's task-optimal leader and scalar uncertainty stay fixed?

The primary behavioral claim is useful access to residual alternatives or their supporting evidence beyond winner/scalar summaries. The stronger opportunity is that donor inference prepares a revisable object another model can use across unseen contingencies. The primary task alone does not distinguish such an object from accessible premises plus fresh recipient inference. That distinction remains explicit throughout the study.

The proposed paper would be consequential if it demonstrated robust counterfactual use of unchosen alternatives, with donor and recipient contributions separately necessary, and explained when donor computation changes this capability. A basic native fact-transfer effect or a win over answer-only text is insufficient for that story. No claim that text cannot express alternatives, no shared-subject claim, and no top-venue guarantee follows.

## Closest prior work and exact increment

[Interlat](https://arxiv.org/html/2511.09149v5), §5.2 and Appendix F, explicitly advances parallel-hypothesis preservation; top-k token mass and productive trajectories are evidence for its interpretation. The proposed increment is an intervention on semantic alternative identity followed by recipient-private evidence and actual appropriate action. It tests that hypothesis more directly, rather than originating it. Interlat trains its actors/interfaces; freezing ours is a constraint, not the scientific novelty.

[Confidence Laundering](https://arxiv.org/html/2606.20662v1), Appendices A.8–A.11 and B, motivates alternatives beyond scalar confidence and evaluates fitted uncertainty predictors. [Beyond Final Accuracy/ICR](https://arxiv.org/html/2610.01042), §§3.1–3.3, already measures actual revision, correction, preservation and recovery when both initial answers were wrong, with a no-message extra-reasoning control. The proposed contrast is residual-alternative intervention under a fixed task leader and uncertainty, not first latent revision or first both-wrong recovery. The planner reopened these originals; detailed source scopes and independent checks are in [late-source-checks](../../late-source-checks.md) and [screening](../../screening.md).

[Dense Latent Communication](https://arxiv.org/html/2606.13594v2) and [LatComm](https://arxiv.org/html/2610.26840) already use encoded private context for later questions; an unforeseen cue alone is no gap. [CodeTalkers](https://github.com/wpm/CodeTalkers/blob/main/README.md) proposes hypothesis-distribution relay; its tiny blend demonstration is a conceptual precedent. [Hidden Messages](https://arxiv.org/html/2610.28905) already has causal content swaps and actual internal return. Bounded source inspection did not locate the precise proposed contrast; this is not an exhaustive novelty certification.

The [dataset card](../../../three_lines_20261025/knowledge/dataset/card.md) separates native influence from useful action. [Pattern P1](../../../three_lines_20261025/knowledge/patterns/question-patterns.md) motivates asking which processing stage contributes. No layer sweep or unique neural representation is needed to ask the behavioral question.

## Task and intervention population

Start with four candidate explanations of a small finite world. A public generative rule and donor-private observations jointly determine the surviving counts of possible micro-worlds. Their class counts are permutations of 8,4,2,1. The sender's evidence must require combining at least two premises; do not simply give it the four posterior probabilities as the scientific task. A minimal implementation could use a public table of micro-worlds and two privately supplied constraints; the table, mappings and constraints must be generated jointly so the exact counts and equal-length counterfactuals are guaranteed. The synthetic check establishes the target distribution, **not implementation or model competence for this rendering**.

The receiver initially knows the public rule and candidate labels but not the donor evidence. Only after donor export is sealed does it receive a truthful membership clue restricting the possible hypothesis classes. The action selects the class maximizing conditional probability, scored against exact enumeration. It is a committed choice in the continuing receiver history, not a discarded probe. No sampled hidden truth is needed for the primary endpoint; expected utility and realized sampled reward can be secondary, clearly distinct quantities.

For each independent episode/layout, cross at least two donor evidence versions with the same leading class and scalar task summaries but permuted residual support, and multiple late clues. Include leader-retained, runner-up and third-ranked optimal outcomes. All changes in oracle action are known from the generator before observing a model response. Use private label permutations and balanced wording/length, and randomize role orientation. Both evidence versions and every cue remain in analysis; do not retain only pairs that naturally agree or successfully revise.

The [264-cell enumeration](finite_world_output.json) verifies the ideal information contrast. For an initial small model check, a fixed six-cell subset is sufficient: donor counts (8,4,2,1) versus (8,2,4,1), each crossed with clues {A,B,C,D}, {B,C}, {C,D}, then relabeled by episode. The second clue requires a donor-contingent B/C reversal; the first retains A; the third requires the original third-ranked C in one donor world and the runner-up C in the other. A larger study should restore all 11 clues and all six residual orderings, prospectively weighted, if competence and cost allow.

## Native timeline and actual state contract

1. Initialize independent sender and receiver caches. Sender sees the public task plus its private observations. Receiver sees only public information. Log exact rendered tokens, IDs and oracle world; no oracle probabilities enter native prompts.
2. From a sender checkpoint after evidence ingestion, create three predeclared branches. **Evidence-stage** has no additional work period. **Inference-stage** runs a fixed 64-token task-reasoning period. **Rehearsal-stage** uses 64 tokens to restate/check the given premises. Each then follows the same actual-choice and fixed neutral 16-token seal procedure. Before the seal, each of the three branches receives the same choice prompt and actually selects and consumes one legal candidate token using the native commitment path. Archive that choice, its decision logits and continuing history on the trajectory that supplies the exported window. The inference/rehearsal branches match work-token count, choice procedure and export position. The early branch has less donor compute and still performs this minimal choice computation; it is not an unprocessed-evidence control. The new runner must implement and verify this order: designated work, actual choice, common seal, export. Exact seal tokenization and forced-consumption implementation require admission review. A forced suffix is an intervention, never evidence of spontaneous identical answers.
3. Export only the 16 seal-position native K/V slots across the existing all-layer interface, using the current untrained route and fixed engineering gain 1.0. Exported contextual states can contain the wider evidence/history; sharing identical token IDs does not make them identical information. Save byte count, shapes, positions, hashes, source history and pending-token state. No sender update or return channel occurs after sealing.
4. Clone a common receiver checkpoint for every arm and cue. Give the receiver its late clue, then inject the fixed recorded donor window throughout the predeclared receiver work and final action stages. Proposed receiver work budget is 64 generated tokens; the seal/import schedule and final `commit_answer` call must be bound in a new runner contract. Same donor archive is reused across late cues, so the sender cannot encode their answers in advance. Do not substitute discarded action probes for commitment.
5. Archive the committed choice and continued history. Restore sibling branches only for diagnostics such as elicited scalar confidence or full alternatives reports. The actual answer and candidate logits are recorded at the real donor commitment, not supplied by a sibling. These reports do not establish what the native action branch represented or used.

The existing [native primitives](../../../mechanism_priority_20261026/source-and-runtime-check.md) support clone/export/replay and actual commitment, but do not implement these prompts, new evidence-ingestion checkpoints or seal schedule. Validate branch isolation, exact repeated export replay, absent late-cue leakage, window length/position and continuing action history before any science run. A cache-only intervention must not silently include donor generated text in receiver input.

## Required comparison and resource ledger

Every arm starts with the same recipient public information and late cue. Count donor and receiver forward tokens, prompt-prefill tokens, generated tokens, sampled attempts, message token count, native tensor bytes and wall time separately. Equal 16 positions is not equal channel bandwidth. One sender realization per branch and one deterministic recipient continuation are proposed; no best-of sampling.

| Arm | Donor information available to receiver | Purpose |
|---|---|---|
| Native inference window | Fixed seal-position states after donor work | Main native treatment |
| Alternative-swapped native window | Same-leader/scalar donor with permuted residual support | Causal content test; score against the recipient's designated true donor world |
| Irrelevant native window | Equal-shaped archive from an independently assigned unrelated world | Presence/disruption control |
| No message | No private donor information; same recipient work | Baseline |
| No message, extra compute | No private information; receiver gets donor work budget as extra tokens | Additional reasoning baseline |
| Actual answer alone | The actual choice consumed on the inference-stage export trajectory | Ordinary winner handoff |
| Actual answer + scalar | The same trajectory choice plus its normalized candidate-choice probability recorded at commitment | Empirical scalar handoff; not oracle matched |
| Oracle winner/scalars | Task leader, 8/15 and entropy; identical in matched donor versions | Exact insufficient-summary control |
| Actual full alternatives report | Donor's candidate-by-candidate probability/evidence report, generated under a fixed 128-token cap before cue release | Strong communicative comparator; its errors are retained |
| Oracle full distribution | Exact labeled class counts/probabilities | Information-sufficient positive control |
| Raw full evidence | Public rule plus all donor observations in text | Competence/recomputation control |
| Native evidence-stage | Same seal after evidence and the minimal actual-choice step, without added work | Early availability comparator |
| Native rehearsal-stage | Same-length donor premise rehearsal, same seal | Processing comparator with equal work/window positions |

Full alternatives reports and supplemental elicited-confidence reports are made from siblings of the common sender checkpoint, with report-generation cost recorded; they are not permitted to improve the native state retrospectively. The alternatives report and oracle distribution are distinct: one measures what this sender communicates; the other guarantees information completeness. Text is a scientifically necessary comparison, not a fallback main study. Matching native performance with a full alternatives report is compatible with native access; it defeats a claim of native exclusivity, which is not proposed.

The full evidence receiver and no-message extra-compute arm receive the same total additional generation allowance as sender-plus-recipient in the main condition; report the resulting unequal distribution of compute explicitly. Also report fixed-recipient-budget versions if collected, with their extra cost counted. The initial cap below includes only one full-evidence allocation, not an uncounted budget sweep.

## Measurement, estimand and uncertainty

For each episode and arm, compute accuracy separately on leader-retained and leader-excluded branches, then average those two strata with weights 1/2 each. Within each stratum weight designated donor versions and cues equally. Call this balanced revision utility U. The **primary effect** is the episode-paired difference U(native inference) minus U(alternative-swapped native). The swapped-donor mapping is predetermined from oracle support and fixed across arms; no effect-based selection occurs. In the six-cell pilot, its {C,D} and leader-retained branches can be identical under a swap; they appropriately contribute zero identification leverage.

Required supporting results are native-minus-no-message and native-minus-oracle-summary effects, the full action confusion table, and donor/cue-specific action reversals. Show the crucial {B,C} choices jointly for both donor versions rather than only pooling accuracy. Success requires responding to both evidence and late cue; indiscriminately copying a donor label does not satisfy it. Report winner retention and third-rank use separately to expose a runner-up heuristic.

Use the generated episode/layout as the independent unit. Donor variants, cue branches, directions, seals and repeated conditions stay clustered within it. Report paired mean effects and episode-bootstrap intervals; for the three required behavioral contrasts use simultaneous 95% intervals through a prespecified max-statistic bootstrap or conservative Holm-adjusted tests plus multiplicity-aware intervals. The stronger post-inference versus rehearsal comparison is a separate, predeclared explanatory family, not substituted if the primary fails. No pooled per-token or branch-level sample inflation.

All prospectively generated valid worlds are included. Record model-invalid actions, technical failures and missing cells separately. Technical missingness is never imputed zero. Report observed paired effects plus missing-cell bounds when completeness fails; incomplete runs cannot be confirmatory. A defined invalid committed action may be a task failure while retaining its invalid status; this scoring distinction needs protocol approval. No natural-answer, confidence or success filtering is used for primary analysis.

Task distributions are not model beliefs. Record empirical candidate likelihoods at actual commitment and supplemental verbal confidence from sibling branches as distinct measurements. Report both donor versions' observed choices, agreement, and task-leader mismatch across every family. Report correct receiver actions that differ from the actual donor choice, with their unconditional denominator; any choice-matched subset is descriptive only. If actual donor choices differ, that family still estimates the prospective intervention effect but cannot establish a same-actual-answer contrast. A headline about alternatives unchosen by this donor requires observed nonchosen-action use; a task-rank label alone is insufficient. A naturally answer-matched subset may be described with its selection rate, but it changes the population and is not evidence that confidence is exactly matched. Only oracle summaries are guaranteed matched here.

## Finite feasibility, freeze and stopping proposals

No model work is authorized by this plan. The following caps are proposed investment limits, not adopted formal N or a power calculation.

**Stage 0: engineering and task audit.** Implement and enumerate the actual multi-premise generator. Reject ambiguous/tied worlds and cue leakage using oracle checks before model execution. Independent runner review must approve state timing, seal consumption, action commitment and append-only ledger. The existing synthetic script does not replace that audit.

**Stage 1: 12 fresh competence families, at most 72 committed outputs.** Per family, two native ordinary private-fact transfers with opposite role orientations; two explicit-full-evidence revised choices; two recipient-own-contract/format checks. Proposed minimums are 18/24 correct native facts, 20/24 correct evidence choices, and 23/24 valid own-contract/format outcomes. Preserve all failures. These admission checks are ACC/format-like capabilities, not the target residual-alternative effect. They do not select a promising hypothesis or tune the bridge against that effect. If a basic prerequisite fails, stop this route; do not replace the main experiment with text or launch a layer sweep.

**Stage 2: 24 fresh layout families, six decision cells and all 13 arms: at most 1,872 committed receiver decisions.** Add 144 actual donor choices (24 families × two donor versions × three export trajectories), plus at most four supplemental report/probability readouts per donor version, 192 total. The common choice prompt and consumed token are counted in all donor branches; the no-message extra-compute/full-evidence allowances also include their generation cost. Seal tokens and prefills remain separately recorded. These are not formal independent samples. Predeclare all materials and thresholds before viewing the target contrasts. Proposed continuation requires ALL of: at least 90% valid outputs in each arm; native balanced utility at least .65; at least 10 percentage points paired improvement over both swapped native and no message; a strictly positive measured native-minus-oracle-summary utility difference; both donor-dependent {B,C} actions correct in at least 18/24 families; the third-ranked {C,D} action correct in at least 18/24 applicable donor worlds; and at least 40/48 correct leader-retained actions. Report empirical uncertainty rather than treating these small-sample counts as confirmation. These are proposed competence/value tolerances for PI approval, not target-data-optimized cutoffs or statistical evidence of population efficacy. Oracle/full-evidence failure makes the task inconclusive. Native fact competence with failure of the revision signature is an informative boundary within this tested carrier/task. Native improvement supported only by simple fact retrieval warrants a narrower report, not automatic flagship promotion.

The independent exact check finds the best summary-only policy has U=7/8 under the stipulated six-cell label/support information, leaving an ideal 1/8 full-information advantage. This is not an upper bound on the measured contrast with an imperfect Qwen summary reader; public generator information and private relabeling must be bound before using that theoretical rule operationally. Consequently no universal .10 margin is imposed on the summary contrast. The new positive-summary, third-rank and paired-reversal conditions repair a logical admission defect, using no model results. A policy that gets both {B,C} choices right but both {C,D} choices wrong must not advance the intended claim.

No prompt, gain, export window or materials are optimized using Stage 2 target effects. At most one clearly justified engineering correction may be proposed after a failed audit; any change affecting scientific meaning requires PI review and fresh families. A second substantive argument repair consumes the family allowance; relabeling does not reset it. This document now incorporates substantive repair 1 for the admission rule and actual-choice contract; independent recheck is required and one substantive repair remains available.

Before a formal study, freeze task generator, cue weights, donor counterfactual map, prompts, reports, window schedule, scoring, missingness handling, comparison family and resource budgets. Calibration, development and formal layouts must not overlap. Formal N is a later PI-approved precision/cost decision after this freeze, using independent paired variability or conservative planning assumptions, never the observed target effect to rescue the question. The existing protocol's M-specific N rule cannot silently be applied to this new endpoint; a new approved protocol is required. No formal N is proposed now.

## What would justify the stronger story

A fresh confirmation should show all three required behavioral contrasts with multiplicity-aware lower intervals above zero and effects exceeding a pre-adopted practical threshold, while maintaining leader retention and showing third-ranked recovery. Practical margins must be set separately for each contrast using its finalized information support, precision and cost; the .10 feasibility margins for swap/no-message cannot automatically become a .10 summary-arm margin. None is currently frozen. Confirm on a second reasoning structure fixed before those outcomes are read—for example, combining independent diagnostic likelihood factors rather than enumerating constrained micro-worlds. This is additional future scope with its own cost/admission, not part of the 1,872-decision cap.

The inference-stage versus matched rehearsal effect should then demonstrate a donor-processing contribution under the same recipient budget and native payload shape. Paired accuracy of ordinary fact questions helps characterize information loss but does not prove equality of all accessible facts. A positive difference supports useful preparation by donor computation; a null allows already-sufficient evidence transmission or an ineffective processing manipulation. Even a positive difference can reflect better retrieval or compression. Uniquely transferred “unfinished inference,” a specific distributional representation, and native superiority to a complete textual report remain unestablished unless additional discriminating evidence is supplied.

An optional mechanism study may substitute the actual inference-stage native window with its paired rehearsal or counterfactual-alternative window at the receiver's fixed action computation, and test the predicted alternative-specific reversal. This locates useful payload dependence at the tested window; it does not identify a unique neural code. Layer/head search, fitted decoders and training are unnecessary for the main question and outside this plan.

## Outcomes and open choices

| Outcome | Supported conclusion |
|---|---|
| Native correct across donor/cue interventions; summary controls fail | Useful access beyond a winner/scalar summary, to alternatives or supporting evidence |
| Native and complete alternatives text both work | Two carriers preserve revisable content; no native exclusivity |
| Post-inference native exceeds matched rehearsal | Donor processing improves later use under this contract; representation mechanism still unresolved |
| Only raw evidence/explicit distribution work | Frozen native implementation has not demonstrated the requested capability; stop this main route |
| Native ordinary facts work, explicit task competence works, residual revision fails | Scoped boundary of useful native access; not proof that no alternatives exist internally |
| Benefits vanish with adequate compute/evidence controls | Ordinary recomputation or resource allocation explains the initial advantage |
| Counterfactual content changes actions without improving utility | Influence, not useful alternative preservation |

Next PI choices are whether this behavioral test of an existing hypothesis is worth a bounded native feasibility investment, whether to adopt the proposed caps/thresholds, and whether the stronger processing comparison should be required before pursuing a flagship narrative. Recommendation: require it for that narrative, while keeping the simpler behavioral question scientifically explicit. Actual multi-premise material generation, tokenizer/serialization checks, runner admission and price/runtime budgeting remain unresolved implementation work. No publication, spending or experimental adoption is implied.
