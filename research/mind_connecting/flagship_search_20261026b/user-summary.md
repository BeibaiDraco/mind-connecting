# Intended user-facing assessment

The leading recommendation is: **Can a possibility I did not choose become the basis of your next decision when our internal states are connected?** This is the most promising new question from this bounded search, chosen for its connection to the original vision, a concrete causal test and manageable first experiment. It is a proposed research priority, not an established effect or a publication guarantee.

The intuitive example uses two frozen instances with separate private evidence. The donor chooses A in the intended task structure. One donor evidence situation supports B as the relevant alternative, another supports C, while the task-defined winning probability and entropy match. The receiver later receives private evidence that excludes A. It must choose B or C appropriately using the imported native state, although the sender never saw the new evidence. Other recipient observations must retain A or change the relevant alternative. This tests whether the connection preserves usable possibilities beyond the current conclusion. Task probabilities are not measurements of the model's beliefs, and a forced identical answer is not spontaneous agreement. Record the donor choice on the actual native export trajectory; sibling reports cannot establish its choice. Retain all prospectively defined families and report observed agreement.

The original literature makes the exact gap important. Interlat already proposes preserved parallel hypotheses and examines broad token distributions and exploratory task behavior. Confidence Laundering already argues for retaining alternatives, with fitted-predictor uncertainty experiments. ICR already tests actual native revision, including both-wrong recovery. Dense Latent Communication and LatComm already encode private information before future queries. The contribution would be a direct causal test of *which* residual alternative another model can use under a specific later contingency. The inspected studies do not supply that comparison; this is a bounded gap assessment, not proof of universal absence.

The plan should compare native state with no message, counterfactual or irrelevant state, actual answer/confidence/alternatives reports, a complete explicit distribution and full evidence, with compute and information budgets visible. The strongest result is a specific paired response pattern following donor residual evidence and receiver private evidence, rather than a higher aggregate score. Explicit alternatives working equally well is compatible with functional native preservation; it defeats a claim of native superiority, not the question itself.

Useful state may transmit raw evidence from which the receiver recomputes. Therefore the first conclusion is functional access to residual alternatives or their evidence. A stronger story about continuing an already-computed thought needs the planned evidence-versus-inference comparison and replication across tasks. Donor processing stages and actual-window substitution offer mechanism opportunities without requiring identification of neurons or a self mechanism. The old source-report findings motivate this focus on actual use but do not establish the new effect.

The completed finite symbolic check supports proceeding to actual task and runner admission, then a small prospective native feasibility pass after PI adoption and execution authorization. Only then invest in broader causal confirmation. A working fact channel with failed alternative use gives a bounded negative answer; a failed channel or uncertain estimate does not. Keep native communication as the main experiment. The recipient-retrieval/rescue candidate remains secondary because fair donor/self-copy comparisons and a useful return path are harder. The main recommendation is positive and specific while preserving these evidence boundaries.
