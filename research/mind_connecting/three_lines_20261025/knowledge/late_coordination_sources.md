## Testing Interchangeability in LLM Agent Teams

[Gao et al., September 4, 2026, original v1](https://arxiv.org/html/2609.05279v1). Read introduction, §§3.1–3.3, experimental setup and §§4.2–4.3 including Tables 1–4. Same frozen model, role and formation length; persistent notebooks separate task and partner notes. Role-matched swaps are compared with roster-change placebo, cleared partner notes, amnesia and naive replacement. Held-out task score changes are smaller than coordination-efficiency penalties; the latter can exceed inexperienced-replacement costs. This directly covers partner-specific history, reassignment, retained task knowledge and mismatched conventions. Four swap pairs are independent units; notebooks are not native KV, and deleting notes changes context length. The task-coupling gradient also changes complexity, explicitly not an isolated coupling intervention. Native implementation alone does not create a new question. A controlled task-interdependence manipulation might refine this account, but its importance and construct validity need an argument beyond filling that missing cell.

## Multi-Agent Transactive Memory

[Kim et al., June 18, 2026, original v1](https://arxiv.org/html/2606.19911v1). Read abstract/introduction and architecture description; methods and full experimental details not audited. Population-level retrieval of agent trajectories is evaluated in ALFWorld/WebArena; the paper reports utility and efficiency without joint training, with an optional learned ranker. This is an explicit external repository rather than proof of native partner-specific cognitive organization. It makes generic “agents reuse one another's procedural experience” an occupied premise. This note cannot decide a fine-grained causal comparison.

## Emergent Coordination in Multi-Agent Language Models

[Riedl, original v3](https://arxiv.org/html/2510.05174v3) and [author page](https://riedlc.github.io/Emergent-Coordination-in-Multi-Agent-Language-Models/). Read introduction, method outline and article's scope statements; not the full information-theoretic estimator or supplementary falsification analysis. The task uses repeated aggregate feedback without direct messages, persona/ToM prompt interventions, and information decomposition to study persistent differentiation and cross-agent complementarity. The primary article explicitly distinguishes conditional synergy under multi-agent constraints from absolute team-over-solo superiority. Generic collective organization, persistent roles and integration/differentiation are already studied; native causal intervention could change what is identified, but that is a candidate requiring a specific comparison. Do not adopt the author's broad ontological wording or treat the metric as a consciousness measure.

Search phrases included LLM partner-specific coordination, conventions, cross-play, transactive memory and collective competence/self-attribution. Further leads (not yet read) include adaptive theory of mind, responsibility attribution using actual versus counterfactual contribution, and long-conversation attractors. Search results are leads, not substantive evidence.

## Higher-order and temporal-belief cautions

[Dynamic Theory of Mind as a Temporal Memory Problem](https://arxiv.org/html/2603.14646v1), Nguyen et al., March 15, 2026: root read introduction and conversation-generation/belief-tracking methods. Controlled LLM dialogues use hidden inner-speech annotations, scheduled belief updates and first-/second-order questions. The reported prior/current belief asymmetry is not independently verified here. Higher-order and historical perspective tracking are therefore not untouched topics. The generation instructions/annotations are not proven action-causal latent belief states; a native intervention could target a different quantity, which requires a precise comparison.

[Belief–Reality Separation Lives in Routing over a Shared Value Slot](https://papers.osteele.com/mental-spaces-belief-26/) was found through its author page. Original arXiv HTML v1 returned 404; the paper itself was not read. It is a required next lead if a proposal depends on untouched belief/reality routing or second-order attribution. [Barr (2004)](https://doi.org/10.1016/j.cogsci.2004.07.002) was only read at original abstract level: simulations can establish conventions without common knowledge. This is a warning against inferring recursive knowledge from coordination, not a fully audited result. Common knowledge is an established logical concept; first-order information access never establishes an unbounded hierarchy of mutual knowledge by definition.
