# Shared internal information, distinct action reference

October 27, 2026. Recommendation for PI assessment, not an adopted experiment. Read the [source audit](source-audit.md) before assigning novelty. This sharpens the existing shared-perspective candidate; it does not reset prior development histories or claim a separate new idea.

## Recommended question

When two independently acting copies exchange contextualized internal state, can useful information become shared while each copy continues to apply it to the appropriate actor? When that fails, does the receiving interface change which actor the information is used for, and can an intervention repair that use while retaining useful transfer?

The motivating distinction is between an event's source, access to its information, and the actor whose action it should guide. A recipient can correctly use another's observation for itself while retaining its historical source. These relations need not coincide. This operationalizes one aspect of the PI's perspective question; it does not measure first-person experience or count subjects.

The strongest possible contribution is a reproducible causal account of when transporting an internal representation preserves its content but misapplies its contextual reference, plus a selective remedy. Merely demonstrating interference, changing a layer, tagging a source, or showing two different correct actions is insufficient by itself. This is a worthwhile leading question to investigate, not an established flagship result or venue prediction.

## Minimal example and decisive comparisons

Use two separate histories of the pinned Qwen checkpoint, with the same team objective. They control two virtual actuators with different mappings. The donor privately observes which world direction is safe. The recipient lacks that fact but knows its own mapping; the donor does not see the recipient's later private mapping change. Export actual native donor state, with no textual answer sent through the principal channel. Record actual donor commitments when relevant; do not substitute task-optimal labels for observed actions.

For illustration, actions are forward/right/back/left, and the correct relative action is `(safe_direction - heading) mod 4`:

| World and mappings | Correct recipient-A action | Correct action under B's mapping |
|---|---|---|
| Safe north; A faces east; B faces west | left | right |
| Only B now faces north | left | forward |
| Only A now faces south | back | right |
| Only safe direction becomes east | forward | back |

This is a specification, not model evidence. The second output asks what should be done under B's mapping, not a prediction of B's actual potentially mistaken choice. Use all four directions and multiple mappings, not a binary case where fact reversal and copied policy can be indistinguishable. Renaming the agents without changing their assignments should not alter task-correct actions.

The key diagnostic uses one fixed exported packet across receiver continuations targeting own versus partner action. A separate sender-mapping counterfactual asks whether A's own action inappropriately changes with B's map while the world and A's map stay fixed. Changing the private world fact must appropriately change A's action. A late recipient mapping change tests flexible recombination rather than copying a precomputed donor answer.

Public mappings can be verified with tool outcomes before transfer; do not claim embodiment from a name in a prompt. The first version may use explicit maps and execution checks. Active discovery of an unknown controlled body is a further task, not a prerequisite and not a new contribution over Paul. For a bilateral demonstration, each agent receives a different useful private observation and both make actual commitments after exchange. Success on restored diagnostic branches alone does not establish successful simultaneous collaboration.

## Three bounded stages

1. **Establish answerability.** Independently verify isolated full-information competence and mapping changes. Test native transfer with true, counterfactual and unrelated donor packets, no channel, a same-source control and explicit text as a positive comparator. An increase in influence without useful fact-contingent decisions is not communication success. Source and format controls should balance length, order and exposure. This stage must use independent capability/access items, not select interfaces on the desired self/other effect.
2. **Measure the functional distinction.** Freeze the interface and materials, then cross sender mapping, recipient mapping, world fact and target actor. Include neutral two-controller tasks with matched information and structure. Measure actual enacted choices, inappropriate sender-map dependence and retained useful transfer. Source reports are secondary. If neutral binding has the same signature, describe an agent-reference problem with implications for self, not a privileged self mechanism. Behavioral signatures constrain explanations but do not uniquely identify an internal mediator.
3. **Test an interface explanation.** Begin with fixed donor exports and cloned receiver states for controlled causal comparisons. Preserve the payload when the intervention permits. Test a specified retrieval/position hypothesis, then corroborate under a second interface setting. Only subsequently test live bidirectional feedback with fresh private perturbations and actual commitments. Exact deterministic replay of the same effective inputs cannot differ merely because its source is not live.

All continuations, sides and counterfactual versions are clustered within the episode/layout. Preserve failures; no filtering on convenient post-transfer success. Sample sizes, equivalence tolerances, selection rules, native serialization, task execution and any new interventions require a separately approved and frozen protocol. Existing native primitives do not certify this new task.

## Connection is part of the causal model

| Axis | What changes | What an effect can initially establish |
|---|---|---|
| Payload: averaged direction versus contextual K/V | Information, contextual structure and representational format | A package-level route difference; scalar access matching is not full matching |
| Receiver operation: residual write, replacement, joint KV read | How local computation is perturbed and whether local evidence competes | A receiving-operation effect, conditional on usable transfer; overwriting local state is especially weak evidence for lost self boundaries |
| Indexing: original versus deliberately rebased key positions; independently varied record layout | Retrieval geometry or how role context is encoded | Dependence on that intervention; position is not identical to semantic ownership |
| Depth/window/timing | Available representations and subsequent computation | An interface dependence; not an identified self layer |
| Fixed export versus live reciprocal updates | Counterfactual responsiveness and accumulated history | Effects of feedback under fresh perturbations, not a count of minds |

Recommended first mechanistic contrast: start from the same exported payload and test the existing positional-overlap explanation with a carefully specified key-position intervention. Rephasing post-RoPE keys preserves values but changes the key tensors, retrieval scores and attention mass; it does not erase contextual position information inside those vectors. Validate the implementation on known same-source cases and inspect attention/access changes. A decrease in errors accompanied by lost useful transfer is not a selective repair. An informative outcome would preserve prespecified useful-transfer performance while reducing inappropriate donor-map dependence in held-out episodes; it supports a retrieval-geometry contribution, not a pure ownership-variable intervention.

Do not assume that an external header retroactively source-tags already contextualized foreign K/V. Re-encoding with a header changes the payload and is a separate condition. Likewise, software separation of banks is not automatically a source distinction available to the model after attention. These details are why connection specification matters scientifically.

STATIC can serve as a historical reference, but it is a poor sole comparator for locating the cause: it changes too many axes. Shallow/full KV sharing is a useful follow-up, already directly motivated by LACO; it should not be presented as our central novelty. No fitted interface, model training or model switch is proposed.

## Mechanism and contribution limits

Correct source/fact reports on sibling branches do not prove those representations caused the executed action. A complete mechanism would need selective interventions on the actual action path and controls for content damage, retrieval competition and downstream policy bias. A source-location manipulation is a tractable first causal dependence, not that full mechanism. Borrowing binding methods for later localization is possible, but fitted probes would require separate scope approval and are not necessary for the initial functional result.

The proposed action task also does not guarantee discrimination from ordinary factual distortion: a sufficiently query-dependent error model can mimic a reference error. Crossed queries and neutral controls reject specific simple accounts, not all possible accounts. Report any remaining observational equivalence explicitly.

If the result is nonspecific degradation, there is no evidence for the intended phenomenon. If simple text/source framing solves everything, report the interface dependence and assess whether it generalizes enough to justify a larger paper. If generic binding explains the result and predicts a selective remedy, that may still be a valuable contribution to latent communication. If multiple validated connections retain both appropriate uses, that establishes a bounded capability rather than experiential independence. The conceptual value comes from explaining how shared access relates to actor-specific control, not from requiring an exotic answer.
