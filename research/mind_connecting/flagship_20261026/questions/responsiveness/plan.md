# Conditional plan: obtaining evidence versus using it

October 26, 2026. **Repair 1**, independently rechecked; bounded corrections closed. **Disposition: conditional extension; flagship value deferred.** The [source audit](source-evidence.md) directly rules out broad adaptive-interaction and communication/exploration novelty. The [development decision](development.md) explains the remaining payoff. All research choices below require PI adoption before execution.

## Minimal setting

Two frozen Qwen3-4B-Instruct-2507 instances must identify a hidden two-bit device code, such as `(red=1, blue=0)`. The two bits are balanced and sampled by the environment; neither instance initially possesses them. Each instance has one opportunity to request a measurement. Measuring a component reveals that bit perfectly; measuring the same component twice leaves the other unknown. Thus the environment, rather than a judge or a self-report, records the exact new evidence acquired.

At a shared checkpoint, A privately receives a newly randomized sensor-availability cue: only its L or R button is available, balanced independently of the hidden code. A commits that button and the choice is frozen. **No observation or bit value is revealed yet.** Capture A's early state after commitment but before measurement execution; only this state can enter B's acquisition input. B then commits its own probe. Only after both commitments does the environment execute the probes and privately reveal their values. B's late result may then return to A, which submits the code. Randomize surface names, component order and which physical side acts first across episode families. Both have the same common objective; B receives no oracle optimal-choice label. A does not revise its committed choice in response to B.

This deliberately small task establishes one complete chain: A's new private condition → A's frozen sampling commitment → B's changed sampling choice → new observations → A's final use. It is not an important contribution merely because an ideal adaptive solver beats a fixed choice. Its purpose is to separate where an otherwise useful internal connection helps or fails. A richer task is unjustified until this works.

## Interventions and why they answer different questions

1. **Acquisition contingency:** From the pre-cue checkpoint, compare responsive A→B state with a preregistered opposite-cue/yoked A→B message. Both live and yoked sender states are captured **before any observation is revealed**, including on the counterfactual branch. Give both branches the same number of model work steps, incoming positions, measurement opportunities and response slots. The yoke preserves marginal cue/message balance but removes correspondence to the current cue. It is a contingency intervention, not an information-equivalent treatment. B then commits its probe; no later success selects the yoke. A post-observation opposite-cue yoke is forbidden because it could import the missing bit.
2. **Final evidence use:** Independently assign the late B→A gate before the episode, but conceal that assignment from both models and every acquisition-stage input, message, clock and prompt. No arm-specific late announcement or timing cue occurs until both probes are irrevocably committed. This prevents anticipation of later pooling from changing acquisition. Then reveal the probe outcomes and apply the assigned late gate; additional paired final forks may estimate the return-path effect within the same acquired-evidence state. Also run an independently assigned forced-complementary measurement arm in which B actually measures the missing component. This is an environmental intervention delivering a known evidence opportunity, not conditioning analysis on naturally successful acquisition.
3. **Transparent controls:** A short explicit report of A's committed button/component, sent before either observation exists, checks whether B can select the complement; explicit delivery of the two acquired values after measurement checks the code decision. These establish task competence and locate a possible bottleneck. They do not certify latent factual equivalence. A source-tagged text route tests whether a found stage-specific failure is shared by ordinary communication.
4. **No-source and duplication controls:** An uninformative balanced message and a yoke from the same cue distinguish absent task content from mere added work or malformed state. A duplicate measurement is correctly scored as no new component even if its bit is repeated confidently. Successful post-cue replay is optional only as a realized-sequence sufficiency check; it cannot establish that the required sequence would have arisen without feedback.

The acquisition gate and final-use gate are crossed. The measured quantity is a finite vector, not a single ambiguous "collective intelligence" score: probability of acquiring both distinct relevant bits; final full-code accuracy; and final-use effect when complementary evidence is experimentally ensured. There is no assumption that post-treatment opportunity conditioning estimates mediation. The forced-acquisition arm changes the policy and therefore answers a controlled intervention question, not the natural direct effect of the live channel.

## Strongest explanatory extension: convergent knowledge, differentiated sampling

The stronger candidate adds a calibration crossover to that same ordered timeline. Both instances have a two-button instrument and must jointly discover the same hidden `(x,y)` code. A's buttons L/R reveal x/y; the fresh private availability cue fixes which A can commit. B's independently randomized, publicly described instrument calibration is either aligned (L/R reveal x/y) or crossed (L/R reveal y/x). Neither receives any value until both probes are committed. Each has one probe; both bits can always be acquired in two probes. No local goals conflict.

| B calibration | Same button choices | Different button choices |
|---|---|---|
| Aligned with A | Same component measured twice | Both components discovered |
| Crossed relative to A | Both components discovered | Same component measured twice |

After A's frozen commitment and before either value is revealed, compare early native sharing, source-tagged text communication, and equally long independent work as inputs to B's choice. There is no two-sided revision loop in this first task. Independently assign early-sharing and late-pooling gates, with the late assignment hidden through acquisition as specified above. All four gate combinations are evaluated from matched initial states, and final forks may improve paired precision. Instrument-map and arbitrary button-name permutations are assigned prospectively. The crossed calibration changes which nominal coordination pattern is useful while keeping the hidden facts, probe number, exact final answer and attainable information unchanged. It does not equalize mapping-reading difficulty; explicit full-information action controls must verify that separately.

The distinctive thesis to test is **whether an internal connection preserves complementary information-seeking behavior while improving A's use of controlled complementary evidence**. For fixed A as leader and B as responder, button-following predicts B changes its button with the fresh A-cue intervention, producing duplication under aligned calibration and complementarity under crossed calibration. Semantic-target following predicts B changes its button with that cue but also remaps it across calibrations, producing duplication in both. Complementary coordination predicts acquisition of both components in both calibrations. Compare B's actual counterfactual responses to cue flips under live, same-cue and opposite-cue early inputs; same-button correlation by itself could result from common prompt bias or a fixed preference. These are rival behavioral response maps. They do not identify literal copying operations, a native code or internal representations.

A native-versus-text difference would distinguish the implemented routes; payload, explicit labels and processing differences remain possible causes. The same pattern in both would be compatible with an ordinary communication/copying account, without uniquely identifying it. The latter is a valid mechanism answer, not an automatic disqualification. A larger conceptual claim requires this relation to survive label remapping and explicit mapping competence controls, with useful late transfer verified. The task still resembles established coordination and collective-search problems; no first-discovery claim follows. Its proposed added knowledge is which level of policy differentiation fails despite usable shared evidence, and whether timing alone preserves discovery without sacrificing later use. That could support a substantial explanatory contribution if robust; at present both the native capability and the literature distinction remain conditional.

The [exact logical check](check_probe_mapping.py) and [its output](probe-mapping-check.json) enumerate four hidden codes and both A-button cues per calibration. With A frozen and B responding, button copying yields one acquired bit under aligned calibration and two under crossed calibration; semantic-component copying yields one in both; complementary coordination yields two in both. Scripted early live/yoked payloads are asserted to contain only the committed plan, invariant across hidden codes and concealed late-gate assignments. Observations are created only after both commitments. With independent balanced bits and no leakage, the ideal full-code accuracy bound is 1/2 after one distinct bit and 1 after two. Count the union of **all** measured or imported facts when applying this bound; any extra value in a prompt, cache, replay or late message invalidates a rank-one claim. The scripted schema has zero imported values before acquisition; it does not audit a future native cache. These are information bounds and scripted-policy predictions, not model performance or validation of a latent mechanism. The extension has not been executed with models and replaces no frozen task.

## Positive, negative and inconclusive outcomes

| Observed pattern | Supported conclusion | Unsupported leap |
|---|---|---|
| Contingent input improves complementary acquisition; return gate improves final code accuracy | A complete useful responsive chain works in this finite task | A new theory of collective cognition or proof of novel discovery |
| B can use an explicit component report but latent acquisition fails; forced complementary evidence is usable through the latent return gate | Stage-specific channel limitation: supplying useful evidence succeeds where guiding its acquisition fails | Interaction generally suppresses exploration; the minimal task lacks an independent discovery baseline |
| Latent acquisition succeeds, but final use fails despite explicit-value competence | A return/use bottleneck after useful evidence collection | No opportunities were created |
| No late latent benefit even with forced complementary evidence | Native-use prerequisite is missing | A meaningful null about responsive organization |
| Matched live and yoke outcomes with useful late transfer and narrow uncertainty | No detected contingency benefit for this specified perturbation/task | Equivalence of all live and recorded partners |

A meaningful null needs enough precision to exclude a PI-selected practically relevant difference; a nonsignificant result is insufficient. Even equal final accuracy can conceal different evidence coverage, but coverage without a consequence for attainable task performance or measurement cost cannot sustain the larger flagship argument.

## Units, analysis and admission

The independent unit is the generated episode/layout family. Cue flips, sides, conditions, repeated decisions and restored branches are paired observations. Average the preregistered balanced cue variants within episode before computing condition differences. Report paired episode-level confidence intervals; choose sample size from an independent pilot and a scientifically selected precision target, not from exposed effects. If claiming both improved use and impaired acquisition in a later extension, prespecify the joint directional claim and its uncertainty rather than selecting whichever endpoint looks favorable. Invalid/missing responses remain separately counted; do not impute them as zero facts or drop failed episodes.

The current pass contains source reading and the finite calibration-crossover check above. Before model work, additionally audit actual rendered prompts for answer leakage, timing, valid sender states and balanced yokes; the logical script does not validate those implementation details. The next admitted diagnostic must use fresh episodes and fixed bridge choices; it must not tune parameters from this target effect. Existing selectors and frozen protocols remain unchanged. Any supported conclusion initially concerns this checkpoint, bridge contract and task distribution; neither a universal property of internal communication nor a human cognitive mechanism follows.

**Kill tests:** stop the novelty claim if a closer source already performs this stage-and-calibration intervention on newly generated evidence and no consequential difference remains; stop the experimental interpretation if useful late native transfer is absent; stop the differentiated-sampling claim if full-information calibration competence fails or the only evidence is the trivial adaptive chain; reject causal mediation language from opportunity-conditioned rates; and stop expanding tasks merely to rescue an unhelpful result. The immediate recommendation is to independently audit the calibration crossover and its closest literature before a finite fresh native diagnostic, not launch a GPU campaign.
