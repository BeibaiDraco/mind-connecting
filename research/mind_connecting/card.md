# Data opportunities and limits

2026-10-20. Documentation, code and a bounded sample were inspected; this is not a fresh full outcome analysis. Corpus identity and prior uses are in [prior_use.md](prior_use.md). Existing outcome summaries are already exposed and can motivate questions, not independent confirmation.

| Collection | Available variation and measurements | What it can and cannot establish now |
|---|---|---|
| V1 hidden-state studies | Live ONE/TWO, STATIC, layer/support interventions; access and source/intent reports | Existing tests of online hidden-state coupling; not a demonstrated useful action loop. |
| Qwen main memory studies and Llama/V5 | Known original assignments, donor counterfactuals, text/STATIC, link-cut timing, third-party conflict | Access/attribution contrasts and source interference. Different cohorts/settings and failed matching cannot be pooled into a single clean experiment. No validated downstream behavior endpoint. |
| V6 two-case interaction pilot | Real native actions, changed world, snapshots, private pulses, cuts/replay | One feedback-dependent correct forward response; no complete correct live return chain in either case. Natural trajectories diverge across arms. |
| V6 channel and fixed-scene diagnostics | Task facts, goal labels, rule answers, action readouts, generated text and native arrays; separated work/readout connection | Distinct influence stages and exposed failures. Fixed-scene actions are discarded answer branches, not committed world actions. |

The current V6 export contains up to sixteen newest generated token positions, across all attention layers, from each sender's contextual K/V. It is not a purified observation channel: note text can describe plans or next states, and each token's K/V can retain wider context. Query-dependent foreign attention competes with own attention; nominal gain is not an equal effective influence across sites or materials. Code: `src/mb/v6_native.py`, `src/mb/v6_goal_stage_diagnostic.py`.

## Executed coverage check

[Script](card_checks/discovery_checks_20261020.py) and [output](card_checks/discovery_checks_20261020.json) read the existing exposed fixed-scene SD `records.jsonl`. The first raw row and first work row were inspected for semantics before the coverage check. Scope: 240 records, two layouts, two focal roles, three donor goals, four work/readout cells, five questions. There are 240 unique keys and 48 cells with five questions each. All recorded action-history lengths are zero. Four receiver-preparation groups remain identical across donor assignments; 24 post-work state groups are shared across readout settings. This verifies suitable branch comparisons and the absence of real committed action in that diagnostic, not new behavioral effects. Full native-array integrity was audited previously; it was not rerun here.

Unit: independently generated paired episode/layout family. Roles, factorial worlds, rounds and readout branches are repeated measurements, not extra independent samples. Missing/invalid native choices must remain explicitly missing or invalid; they are not zero-valued action bits. Own-goal label, own-rule report, actual action, source claim and competence forecast are different measurements.

## Important dissociations

| Distinction | Existing leverage | Missing evidence |
|---|---|---|
| Access versus attribution | Main memory route comparisons | Generality beyond tested task/interface; no universal steering exclusion |
| Work effect versus direct readout effect | W0R0/W0R1/W1R0/W1R1 shared-state branches | Useful downstream use; persistence mechanism |
| Fact use versus donor-goal sensitivity | Fixed own state and varied donor assignment | New balanced actual-action task; assignment changes whole donor state |
| Influence versus useful return | Directional cuts and replay | Reliable informative messages and a complete appropriate return |
| Ability versus self-estimated ability | Not jointly measured | Prospective forecast and paired connected/cut challenge outcomes |

The structural check enumerates sixteen binary worlds and six ideal policies. Five wrong alternatives all have 50% accuracy but different complete intervention patterns. Therefore an accuracy table cannot identify the failure. Moreover, a donor-goal-dependent distortion of the perceived fact can exactly mimic adoption of that goal. This counterexample limits even a successful response-pattern analysis: it can establish functional selectivity, not uniquely localize goal replacement.
