## Figure style

All figures share `scripts/figstyle.py`: Arial; A blue, B vermilion, Robin gray; "claiming" uses B's color, meaning B's content shows up in A. The colors of two-way paired outcomes show whose rule each side ends up holding (A adopting B's rule uses B's color), consistent with the meaning of the color blocks in the GPT illustrations. Full width 5.5 inches (NeurIPS/ICLR single column), vector PDF with embedded fonts, plus a 300 dpi PNG. Three commands, run in order, redraw all figures and the booklet: `make_paper_schematics.py`, `make_paper_figures.py`, `make_paper_booklet.py`.

## Paper structure

`paper/STORY.md` is authoritative (from 2026-09-25 it supersedes the structure draft that used to be here and sections 1–4 of `PLAN.md`). Technical fixes to the figures follow `docs/reviews/paper_plan_review_codex.md`.

Writing discipline: no claims of consciousness, number of subjects or phase transitions; write preregistered and descriptive results separately; report failures and negative results truthfully; every number must be traceable to a report in `docs/results/` or to the raw records.
