# V6 execution preparation review

Scope: the prospective continuous-interaction collector, neutral admission,
native stage worker, immutable material/source admission and external supervision.
This is a new review record; historical reviews and protocols are unchanged.

## Independent scientific and engineering review

The neutral-task author and neutral-admission author independently reviewed each
other's implementations. The native worker was reviewed independently by both
agents. The root reviewed integration and resource admission; the analysis agent
independently reviewed the prepared-package binding and generation scripts.
The external supervisor passed separate cross-author operational review.

The neutral collector uses independent continuing task/CAP and fresh-fact
streams. Actual action tokens determine later private states; discarded probe
answers do not enter either continuing history. Physical sides and readout
families remain separate, with the base episode as the statistical unit.
Selection uses complete raw neutral data only, all three disjoint candidate
cohorts, the smallest passing gain and one independent validation cohort.
Scientific effect readouts cannot select a setting. Original failures are not
reclassified and validation failure does not authorize a replacement candidate.

Review corrections included a common task-content fingerprint across neutral
and main material wrappers and comparisons against every ancestor cohort. A
separate authority receipt now pins the prepared material catalog, preventing a
fresh same-stage cohort from silently replacing a failed one. Historical proof
resolution preserves original bytes and cannot grant live execution permission.

The native worker validates actual fixed stage materials, independent real
checkpoint acceptance, source/model identities, complete smoke and byte-identical
resume before scientific collection. Its raw rows retain actual native output
alongside diagnostic logits; it cannot substitute a synthetic backend. Main
episodes retain all sixteen prescribed artifacts. At most one exact-identity
episode retry is allowed, retained successes must match, and incomplete or
unindexed archives fail closed. A completed but failed neutral gate remains
complete retained evidence and does not grant the next stage.

## Operational findings addressed before deployment

The control host must own actual provider-state confirmation. A remote child
cannot prove that its own instance stopped. The new supervisor uses a separately
pinned private adapter, exact-target requests, one durable launch intent,
detached execution and an independent deadline guard. An ambiguous create or
launch result must not cause a repeated request creating duplicate resources.

Review identified interactions between long backups and short-lived admission
proofs, adapter descendant processes surviving timeout, locks scoped too narrowly
to protect one target, missing monotonic deadline protection, and final inventories
that could omit scientific files. These were corrected and covered by explicit regression checks;
successful stop requests alone never establish actual stopped state.

The storage estimate also invalidated a simplistic fourteen-minute full-backup
rehash deadline: hundreds of GiB can take substantially longer on an SD card.
The prescribed correction is bounded incremental verification while paid,
closed-inventory final copying, actual provider stop, then full independent local
rehashing. Cached periodic verification is explicitly distinct from a freshly
rehashed final backup. Terminal success requires all three: complete data,
verified final backup and actual stop.

## Boundaries still requiring real commissioning

This review does not establish real native attention/cache correctness, model
task competence, throughput, storage growth, backup speed or scientific results.
Those require the real pinned-checkpoint acceptance and fixed smoke materials.
Do not replace them with tiny random-model tests or mocked provider receipts.

The private provider/SSH adapter, fresh creation intent, exact new machine
binding and both actual guards still require deployment commissioning. The
generic supervisor alone does not make a cloud launch ready. Monetary ceilings
and newly explicit scientific rules remain a prospective package pending the
PI's ratification. No V6 instance, model execution, new financial anchor,
automation or formal science freeze has been created by this preparation.
