# Independent review: address, source features, and ownership

**Reviewer:** Codex. **Date:** October 27, 2026 (Chicago). **Reviewed dossier:** `research/mind_connecting/address_ownership_20261027/`, commit `e8792ef`.

## Overall judgment: promising with fixes

**Recommend a bounded positional-intervention study, but reject the proposal's central “exact symmetric zero point” justification. Do not yet promote the whole source-feature program to the flagship paper.** The established attribution phenomenon makes this a more economical next mechanistic experiment than immediately building my actor-reference task. However, the current proposal contains a false symmetry inference, an inadequate replacement for behavioral access, and several interventions whose predicted interpretation exceeds what they isolate.

The valuable question is narrower: **can retrieval geometry change which original record an imported assignment is attributed to, while preserving counterfactually verified use of the imported information?** A selective, reproducible repair would explain a consequential failure of internal-state sharing. An attribution reduction caused by suppressing the donor would not. Source-feature decomposition is a useful organizing framework, not itself a new theory or a demonstrated mechanism of self.

I read the five requested files in order, inspected implementation and protocols, independently aggregated seven raw record sets, reconstructed all 600 V3 tokenized card pairs, inspected saved tick schemas, and reopened the closest primary literature. This is a review and recommendation, not adoption of a question, metric, selector, sample size, model, or experiment. No model was run and no dossier, manuscript, or frozen protocol was edited.

## A. Fact checking

### A1. Symmetry: disagree with the concession as written

The withdrawal of “we discovered that one's own memory has no home advantage” is sensible. The replacement claim—“50% follows by construction”—goes too far (`internal_evidence.md:35–43`; `proposal.md:7–22`).

At equal weight, joint attention is invariant to permuting the accessible key/value pairs **with the query and the accessible multiset held fixed**. That is not exchangeability of the complete experiment:

- The query comes from A's computation, not from a symmetric mixture supplied independently of A: `src/mb/runtime.py:90`.
- A's own attention includes its local history and current computation. The foreign P mask excludes B's generated C/R history: `src/mb/runtime.py:92–102,361–370`.
- The prefill includes separately generated notes, and its final state seeds A's continuation: `src/mb/run.py:676–686`; `src/mb/runtime.py:334–359,483–504`.
- Similar aggregate own/B mentions in linked reflections do not make the underlying states exchangeable. They are post-treatment text summaries.

A counterexample is enough: let A's query align strongly with its own rule key and weakly with B's. Equal external weights still give A a home advantage. More generally, a system where **each agent always selects its own rule** remains equivariant when A and B are renamed. Agent-swap equivariance therefore does not entail 50% donor selection. A proof would require an input transformation that preserves everything available to the receiver while exchanging the correct-own and donor labels; the implementation does not supply that transformation.

**Required wording:** near-half donor selection is an empirical result of these interfaces, tasks and weights. It is compatible with several competitive-retrieval explanations and does not establish a special property of self. It is neither a theorem nor merely an implementation check. A Bradley–Terry home coefficient can describe residual bias; it cannot prove the missing symmetry premise.

This also invalidates “every source-monitoring feature is equalized exactly” (`novelty_audit.md:129,154`). Different names, assignments, contextualized histories and receiver queries remain. The human framework concerns memory characteristics **and judgment processes**, including criteria and background knowledge; its original overview does not give the proposed quantitative theorem. See Johnson, Hashtroudi and Lindsay, [original paper, printed pp. 4–5](https://memlab.yale.edu/sites/default/files/files/1993_Johnson_Hashtroudi_Lindsay_PsychBull.pdf). An artificial condition hiding every source distinction would instead make source recovery unidentifiable by definition; creating it would not by itself be a scientific discovery.

### A3. Conclusions that need correction

**Disagree** that the strict-third-person arm already establishes a null effect of small RoPE shifts (`internal_evidence.md:33`). It changes wording, token lengths, the note opener and resulting states together. At w1, donor choices fall from 52.33% to 47.75%; the formal M difference is −3.211 nats, p=.000158, in R3 `log.txt`'s T3_w1 contrast. Neither an isolated positional null nor “names do nothing” follows. The defensible conclusion is that this known-other naming package does **not sufficiently protect attribution**.

**Disagree** that the only surviving mechanism is a shared holder record, that conflict is absent internally, or that relocation preserves “exact K/V” (`internal_evidence.md:69–77`). Several retrieval/competition/readout accounts remain; unprompted silence is not a sensitive detection test; rephasing changes K while holding V fixed. Its effect does not exhaust all possible position information already contextualized inside K/V.

**Additional raw check:** in V5 conflict arms, ordinary START never chooses either Robin candidate, in either line-order group. But qualified PROV_SELF_RULE does. When B's Robin line is in the same ordinal slot as A's holder line, Qwen selects the donor-only conflicting Robin rule in **260/600 = 43.33%** of presentations, versus **195/600 = 32.50%** with equal holder-line order. Llama gives **61/600 = 10.17%** versus **69/600 = 11.50%**. These are descriptive splits, not new confirmatory tests. They show that “never Robin” is readout-specific; they neither establish nor universally reject a positional mechanism. The TAG/UNTAG comparison does supply evidence for a framing effect on the same quoted B reflection (`src/mb/tasks.py:403–407`; `docs/protocol/PROTOCOL_V2.md:64–69`). It does not isolate a header applied to unchanged foreign K/V: the KV/text comparison changes content and encoding together.

## B. Novelty and scientific value

### B1. Framework: agree with its usefulness, disagree with its novelty claim

The dossier correctly locates the idea inside our existing draft (`paper/sections/account_and_discussion.tex:1–32`) and correctly gives substantial credit to previous work. It overstates novelty again when it makes exact equalization the contribution (`novelty_audit.md:151–154`). Factorially varying source cues is not new as a scientific strategy. The potential contribution is an identified failure and selective intervention in **separately contextualized internal states**, with consequences beyond verbal ownership.

The source-monitoring analogy is useful for separating retrieval cues from historical origin. The theory does not forbid representations of explicit source labels; its claim about inference is more qualified than “humans store no tags.” It does not establish that LLM records instantiate all human feature classes, predict this exact sigmoid, guarantee a home advantage from derivation, or imply a monotonic layout/language effect. Background knowledge and judgment criteria also matter in the original theory. Likewise, philosophical quasi-memory motivates the question; our task does not instantiate or resolve personal identity or private experience.

## C. Design review

### C1. RoPE relocation: feasible, with a sharper intervention contract

**Agree** that `k_par` after fp32 conversion is an appropriate place for a read-time rephasing intervention (`src/mb/runtime.py:97–107`). **Disagree** with calling every proposed version equivalent to a genuine offset prefill (`proposal.md:41–50`).

1. **Specify the sign and coordinates.** For a desired apparent position change δ, use `R(δ) K_cached`; earlier means δ<0. Positions must be logical non-padding RoPE positions, not left-padded cache columns. Store the per-row source position map, selected span and δ. A global constant based on batch length can change treatment with batching (`runtime.py:337–342,361–370`).
2. **Distinguish whole-sequence translation from partial rephasing.** With stationary RoPE frequencies, uniformly translating every position in an independently prefilled sequence preserves its internal relative geometry in ideal arithmetic. Rephasing only the divergent tail while leaving its earlier prefix fixed is a different intervention: original K/V already encode interactions with that prefix. A real prefill with only that tail displaced recomputes those interactions and need not agree. Use the real-offset equivalence check for the whole-sequence case; label a partial intervention as read-time apparent-position surgery.
3. **The 181-token treatment is not universal.** It is the second-person longest common prefix; strict third person diverges at 29. Either preserve the historical complete-bank anchor and translate the complete foreign P bank, or introduce a separately named semantic-tail/deduplication condition. Do not silently treat the first 181 third-person tokens as duplicate. When truly identical keys/values are duplicated at the same positions, their combined unnormalized mass is multiplied by `1+w` (log 2 at w1), relative to nonduplicated material. This is a common-prefix normalization effect, not an own-bank advantage. Deduplication changes the experiment, not just efficiency.
4. **P is more than the card.** It contains the generated note, closing tokens and reflection prompt (`run.py:676–686`). Moving the card but leaving the note behind can preserve a second source of the same assignment at its old position. Default to a precisely specified complete P export for the first clean key-only test; treat segment-specific interventions as follow-ups. Log actual note spans.
5. **“Later, inside A's reflection” needs a realizable map.** A divergent tail plus a note and prompt can be longer than A's 48-token reflection. It cannot automatically fit into that interval. RoPE can assign virtual negative/future coordinates, but the existing mask still operates on original cache columns. Such an intervention does not create a genuine earlier/later document. Specify overlap, masks and valid query-relative distances explicitly before comparing primacy with recency.
6. **Own-bank moves require more than rotating `k_own`.** The ordinary attention output is computed first at `runtime.py:77`; `o_own` later reuses it at line 108. Rotating only the fp32 own logits would change the mixture weight while leaving the within-own output unrotated. A valid own-position intervention must recompute that output consistently. Avoid in-place cache mutation, especially because the same rows serve as donors and snapshots are branched.
7. **Use the loaded model's actual rotary frequencies and pairing.** Do not assume base 10,000 or interchangeable rotate-half conventions. For a later approved Llama experiment, honor its frequency-dependent scaling; do not apply any cosine/sine amplitude scaling a second time to already rotated keys. Dynamic scaling variants require their own equivalence conditions. This review authorizes no new model; the proposed “then Llama” needs a separate PI decision under `AGENTS.md:74`.

Necessary engineering checks: explicit δ=0 bypass reproducing the old path; sign/orientation tests; norm preservation and δ/−δ recovery within stated floating-point tolerance; full-context translation comparison; padding/batch invariance; untouched-source and snapshot checks; mask-span checks; finite values and GQA head alignment. Bit-identical inverse rotation is not a sensible requirement after rounding. These are future acceptance checks, not checks performed in this review.

### C3. Analysis and selection: retain dose curves, reject attention as the sole access axis

**Agree** that ACC is source-qualified and that matching a scalar ACC gain cannot equate usable information. **Disagree** that the C0 Robin bias proves ACC matching favors the slot account, or that attention mass solves the problem (`proposal.md:64–70`). Raw attention measures routing, not whether the donor fact can be correctly used. Information may occur in contextualized note/prompt states outside the rule tokens; attention can be high without relevant value use. The attribution question's own query also affects its attention pattern.

Recommended primary evidence is the **joint outcome**: improved correct source separation **and** retained donor-dependent behavioral performance, with CAP and format intact. A new donor-only fact used in a neutral computation could supply an attribution-free behavioral access test, provided full-information/no-link/counterfactual-donor controls validate it. It must require the imported fact, not simply ask which rule is B's. This is a proposed new endpoint requiring PI adoption, not a ready-made validated metric. Keep original ACC as a reported continuity measure. Do not discard difficult episodes based on post-link access success.

Keep the fixed weight grid as a descriptive response surface. A 50% crossing is a secondary summary **only when the observed grid brackets it and the fitted curve is adequate**. Repair might remove the crossing entirely; slope and asymptote may change; multinomial Robin/spare errors must remain visible. Mixed logistic coefficients are conditional, so derive population-level curves by averaging over the declared episode/rule/order distribution rather than calling a conditional intercept ratio the observed population threshold. Cluster all uncertainty/resampling at the episode level.

Delete “curves must converge at high w.” Large w makes a head's mixture donor-dominated, but does not remove receiver residual state or MLP processing, and shifted donor keys can select different values. The proposal's limited grid also cannot establish an asymptote. A horizontal shift in ownership and a vertical change in attention are not comparable units. Even two fitted horizontal shifts require a prespecified attention reference level and uncertainty; their difference is descriptive, not a causal decomposition. Matching or conditioning on post-intervention attention cannot by itself identify an ownership-specific mediator.

**AGENTS §5.2:** estimating ownership curves after a frozen design is allowed analysis. Choosing positions, weights, prompts, layer subsets or “best” repair using those curves is prohibited target-based selection. Attention is not currently an authorized selector input either: `AGENTS.md:75` permits ACC, CAP and format. A new protocol would need an explicit PI-approved access definition, selection whitelist, fixed geometry/grid and tie-breaking, disjoint development/variance/formal splits, failure rules, primary estimands, multiplicity, equivalence/noninferiority margins, and a sample-size rule appropriate to the new outcome. The existing paired-variance-of-M rule cannot silently become a power calculation for a crossing or binary separation rate. Blind safety/access qualification can precede fixed-parameter exploratory outcomes; any later redesign starts a transparently new development cycle, never an adaptive search for the strongest ownership effect.

### C4. Step 2: feasible components, not a clean ready-to-run factorial

- **Own processing: conditional support.** Derivation versus supplied answer changes evidence, computation, repetition and token budget. Include a yoked replay of the same derivation tokens in the same effective role/context, plus balanced donor/receiver traces. If complete effective states are identical, actual historical authorship is inaccessible; no model test can recover it. The scientific variable is the available processing trace/context, not an invisible act of having generated it. Both old agents already generated their own notes, so this is not adding self-processing from zero (`runtime.py:483–504`).
- **Format: support layout first, defer language.** A table or moved assignment changes tokenization and contextual binding as well as similarity. Use counterbalanced layouts, no-link competence and access checks; do not promise a monotonic psychological similarity gradient. Language adds capability and token-length confounds with little early discriminating value (`proposal.md:84`).
- **Prefill vector injection: defer.** Existing hooks explicitly forbid writes outside single-token tick mode (`src/mb/bridge.py:200–231`; `runtime.py:344–351`). A position mask, per-position normalization, downstream recomputation and new calibration/identity tests are needed. The old rule-conditional STATIC direction is not an ownership direction. A positive effect would show timing/context dependence; it would not establish the proposed introspective consistency mechanism (`proposal.md:85`).
- **Detection probe: feasible, secondary.** Use held-out no-link and same-content/sham conditions, randomized answer order, sensitivity **and false-positive rate**, and a prespecified scoring rule. Informing every run that insertion may occur changes response criteria. Compare localization/attribution with detection; do not equate a “yes” response with introspective access. Open reports can supplement this without being its ground truth (`proposal.md:72–79`).

### E3. GPU estimate grounded in saved runs

The “several GPU-days, not hours” estimate is plausible for the **entire** proposed grid under conservative batching, but is not a defensible estimate of a minimal study without specifying hardware and batching (`proposal.md:87–94`).

- R3 ran on **H100 80GB**, batch 40 episodes. Ordinary KV w1 consumed **2,375.4 seconds for 600 episodes**, about **3.96 seconds per episode-arm**. The complete seven-arm run was about **3.39 hours**. Evidence: R3 `manifest.json:4–17`, `config.yaml`, `log.txt:32` onward and final timestamp.
- R5 ran on **A100 80GB**, batch 2 episodes. Ordinary KV consumed **16,894.1 seconds for 600**, about **28.16 seconds per episode-arm**; the complete three-arm run was about **12.25 hours**. Evidence: R5 `manifest.json:4–17`, `log.txt:2–4` and subsequent chunk entries. This difference is confounded with batching, question suite and runner details; it is not a hardware benchmark.

Use `hours ≈ episode-arms × measured seconds/episode-arm ÷ 3600`, then add smoke, warmup, logging and rerun allowance. For roughly 660–880 pilot episode-arms, the historical anchors imply **0.7–1.0 H100 hours or 5.2–6.9 A100 hours before allowance**. For 6–8 formal arm-equivalents at N600, approximately **4.0–5.3 H100 hours or 28.2–37.5 A100 hours before allowance**. Reserve roughly **1–3 / 6–10 hours for the pilot** and **6–10 / 35–50 hours for formal collection** under the respective historical batching regimes. These are capacity estimates, not bookings or price quotations; a timed smoke must replace them before spending.

A 3-placement × 2-frame × 5-weight × N300 grid alone is 9,000 episode-arms: approximately 9.9 or 70.4 hours before controls. Thus the large program can cost several days, but it should not be the initial commitment. Per-head logging should stream compact span summaries; losing batch capacity to full matrices could dominate cost.

## F. Stopping conditions

**Agree that explicit stops are needed; disagree that every outcome supports a flagship.** Apply the following to the frozen, adequately measured contrast, not to a search for better prompts after disappointment. References: `proposal.md:27,64–70`; `research/mind_connecting/connection_scope_20261027/proposal.md:35–43`; `AGENTS.md:75–78`.

1. **Stop the ownership-repair claim if source improvement occurs only with loss of donor-dependent use**, or with comparable same-content/CAP disruption. That is attenuation or damage, not selective source repair.
2. **Stop the positional explanation if a validated displacement spanning the declared hypothesis range has a precise effect below the prespecified meaningful bound**, while transfer remains adequate. This refutes that bounded positional hypothesis; it does not prove that all ownership lives in content or justify an unlimited feature sweep.
3. **Stop promotion if results reduce to content preference, answer-position bias or generic entity-binding interference with no new predictive consequence.** A BT fit or an isolated displaced-key effect alone is a modest descriptive/mechanistic extension. Generic binding can still support a strong paper if it explains consequential communication failures and a selective remedy; it simply limits self-specific claims.
4. **Stop claims about shared useful cognition if the independent transfer assay cannot be validated.** A positive text oracle with failed native transfer diagnoses interface feasibility, not a philosophical boundary.
5. **Stop the full program after the bounded pilot if only labels/formats that rewrite the task produce gains, no selective result survives held-out layouts, or the result needs target-based tuning prohibited by the project.** Preserve a negative/update result for the existing manuscript rather than expanding indefinitely.
6. **Treat imprecise nulls or failed implementation checks as inconclusive**, with at most the prospectively authorized repair/sample plan. They are not evidence for the opposite mechanism.

## G. Publication judgment

**As presently justified, no: this does not yet support a top-conference main-track paper. As a corrected mechanism-led extension, it has a plausible route.** Its advantage is a strong existing empirical base; its weakness is that the proposed headline is a familiar source-cue idea built around an invalid exact-zero assertion. By October 2026, Li, LACO, Goals Leak, ParaThinker and binding work already occupy the broad claims about self slots, ego interference, source-bearing state and contextual binding. Adding a philosophical name or several prompt variants will not create the missing contribution.

The package would become substantially stronger with:

- a **causal dissociation** between usable imported content and correct record-source assignment, established by a selective intervention rather than a scalar access proxy;
- **predicted generalization** to held-out layouts and questions, including the qualified-self/Robin counterevidence, so the account explains more than the readout that motivated it;
- **one consequential two-agent use case**, preferably independent actor-reference/action use, showing why the source-binding error matters and whether repair preserves collaboration;
- an explicit separation of ordinary relational binding from any proposed self-specific component, and precise claims about the tested connection mode.

A full neural circuit is not necessary for a valuable causal interface result. Conversely, an attention plot or decoding probe alone is insufficient to identify ownership. No second model is mandatory to make the first study informative, but one narrow artificial assignment task needs stronger within-model generalization and practical consequence to compete at that level. Any model extension remains a separate PI decision.

**Final recommendation:** approve the corrected, bounded development direction for discussion—not the full source-feature program. Test the draft's positional premise cheaply, require preserved useful transfer, and use a successful result as a bridge to actor-specific action. If the positional result is null or merely suppresses B, report that limitation and reconsider the actor-reference question without presenting source-feature enumeration as the flagship discovery.
