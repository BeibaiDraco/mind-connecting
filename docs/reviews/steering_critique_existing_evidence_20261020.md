# What the existing paper establishes relative to steering

October 20, 2026. Evidence reconciliation requested by the PI after the connection-placement discussion. No new experiment, selector, protocol or implementation is adopted.

## The criticism that must remain visible

Locating an effective injection site does not, by itself, distinguish this project from ordinary context-derived activation intervention. A vector does not acquire a special mechanism merely because it came from another model instance. The earlier response about functional placement was incomplete: it addressed recipient mechanisms without resolving the existing paper's connection-versus-steering question.

The project already contains three relevant kinds of intervention. They must not be rediscovered as new proposals or collapsed into a single negative control.

| Existing intervention | What was actually done | What the result can support |
|---|---|---|
| V1 hidden-state bridge | At each decoding step, normalize B's layer-24 output and inject it into A's next-step block input; ONE and TWO were both tested in a separate N300 study | Donor-dependent content effects with weak access and no observed donor claiming across the reported arms; not a clean matched-access rejection of all live hidden-state connections |
| STATIC rule direction | Calibration mean conditioned on a rule minus the overall mean, injected into the residual stream | A specific averaged direction comparator; it is not the family of all episode-specific, contextual, tokenwise or time-varying interventions |
| Main memory link | Recipient queries can retrieve donor K/V records alongside its own records | A structured, query-dependent memory intervention with source-attribution errors; main fixed-memory results do not require a donor responding to the recipient |

Source: [preserved hidden-state appendix](../../paper/sections/appendix_v1.tex), [main results](../../paper/sections/results.tex), and [original protocol](../protocol/EXPERIMENT_DESIGN.md). The main memory link and later live generated-state V6 interface remain distinct implementations/studies.

## Positive evidence and its exact limit

Qwen v3 has mean rule-access gains of 4.081 nats for KV and 4.179 for STATIC, alongside donor-rule claiming of 52.3% and 0%. This is evidence that the matched mean access statistic does not determine attribution across these two treatments. The paper itself states that the treatments differ in more than access and the comparison does not identify which difference causes the outcome.

The later Llama comparison gives assigned-rule donor choices of 49.917% for KV and 0.583% for STATIC, but formal mean access gains differ by approximately 40.1%, failing the frozen 25% match. It must not be described as a second matched-access replication. Nor is STATIC universally inert.

Conflicting third-party records also produce source errors in both models. A self-specific explanation is therefore not established. The old positional/card-slot account is a hypothesis, not a localized circuit finding. Completed evidence and exceptions are summarized in the [post-collection assessment](../paper/post_collection_story_20261012.md).

Thus the current paper contributes an empirical distinction between access and attribution across particular communication routes. It has not ruled out context-state substitution, retrieval competition or general source binding as explanations, and it has not established a categorical mechanism beyond activation intervention.

## Three questions that should not replace one another

1. **Content/representation:** Can an averaged direction, an episode-specific state or a structured cache explain the observed source behavior? STATIC answers only one part. The V1 live hidden-state result is also real evidence, but access and operator differences limit it.
2. **Recipient mechanism:** Which operation, processing phase or component produces the distinction? Placement experiments can explain the existing observation. Merely finding a more effective layer does not establish a responsive partner effect or a special self mechanism.
3. **Reciprocal dependence:** Does a donor's new response to the recipient make a causal difference? This requires an intervention and return-path comparison under a specified interface, not merely knowledge that the payload was generated by another model.

A future same-interface comparison could hold K/V format and recipient access operation fixed while changing whether donor states are frozen, freshly generated without recipient feedback, or generated with feedback. Exact identical replay in an identical deterministic receiver is expected to agree. The informative contrast follows a new private perturbation for which the live partner can generate a contingent response. Subsequent content differences are part of that causal path; a stale tape alone is not a sufficient control for freshness. This is an explanatory direction, not an approved next run.

Even a genuine closed loop can be described mathematically as a sequence of state-dependent interventions. An unrestricted history-dependent steering procedure that reproduces the entire partner computation could reproduce that loop. The scientific target is therefore a specified causal dependency and functional organization, not proof that no steering description is possible.

## Consequences for current planning

Keep the observed KV-versus-STATIC attribution dissociation as an empirical anchor. Treat functional localization as a way to explain that result, not as a replacement question or an automatic novelty claim. Test reciprocal dependence separately when making claims about the original two-responsive-systems vision. A one-way mechanism finding remains worthwhile on its own terms, without being relabeled as evidence for the stronger interactive claim.

The recent two-case live pilot has one feedback-sensitive correct forward response, failed return actions and a second unsuccessful case. It does not yet close the reciprocal-dependence argument for useful interaction. The [full pilot report](v6_small_interaction_results_20261019.md) retains all cases.
