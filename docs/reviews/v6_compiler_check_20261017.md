tests, the original 75 package pins and the 97-file deployed source/asset tree.

start, all historical costs and reserves. It did not renew the expired general

The instance restored at 17:22:11 UTC. The 4,703,399-byte deployment timed out
after 90 seconds, with only the receiving phase observed. Remote guard and
worker dispatch were never reached: zero CUDA tests, model comparisons or
scientific episodes ran. Actual stop was confirmed at 17:24:57 UTC, 165.83
seconds after restore intent, then independently queried again. The exact local
controller and guard had exited. Automation was paused.

The 47 final control files and 130 prelaunch files were independently rehashed
on the SD card. New closure and billing audit receipts were also backed up.
No remote experiment backup is claimed: the controller's remote-backup flag is
false because deployment failed before any worker. The stopped disk remains
retained and billed. Historical failures and the older 61-file backup gap remain.

## Concrete operational error

The preceding successful 4,698,604-byte upload spanned approximately 95.37
seconds between its archive and completed transport-log timestamps. Choosing a
90-second timeout for the new full upload therefore lacked observed margin.
The author and independent reviewer missed this feasibility check. These file
timestamps are an approximate operational observation, not a controlled network
benchmark; the latest timeout does not identify a CUDA or scientific failure.
